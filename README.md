### Чем занимаюсь

Разработка Telegram-ботов и ВКонтакте-ботов для бизнеса, сайтов и интернет-магазинов на Nuxt и WordPress, VPN-инфраструктуры и приложений для Android и Windows. Строю системы, которые работают без меня: принимают деньги, ведут учёт, чинят себя по расписанию и присылают отчёт, когда что-то идёт не так.

Специализация — **асинхронные Telegram-сервисы с реальной бизнес-логикой**: биллинг, подписки, тикет-системы, корпоративный учёт. Это не боты-визитки, а продакшен с транзакциями, миграциями и живыми пользователями.

Отдельное направление — **суверенная сетевая инфраструктура**: распределённые VPN-трассы РФ → Европа, маршрутизация трафика, администрирование узлов, собственный VPN-клиент.

За последний год добавились ещё четыре линии работ:

- **Сайты и магазины** — интернет-магазин на Nuxt 4 + FastAPI с админкой для владельца, витрина на WordPress под мобильный трафик, миграция с Joomla на WordPress с сохранением позиций в поиске, сайт студии на Nuxt Content.
- **Embedded и IoT** — прошивки ESP32 и хаб на Raspberry Pi для B2B-игровой системы: протокол на радиоканале, расчёт на краю сети, работа при потерянной связи с сервером.
- **Медиа-инфраструктура** — приём и раздача видеопотока с низкой задержкой, WebRTC-голосовая, авторизация эфира на уровне nginx.
- **Обследование объектов и аудит** — инвентаризация сетей и видеонаблюдения на действующей площадке, аудит сайтов и рекламы в Яндекс Директе, комплекты документов для заказчика.

- **Асинхронный Python** — aiogram 3, asyncio, пулы соединений, фоновые задачи на APScheduler
- **Проектирование БД** — нормализация под реальную предметную область, идемпотентные миграции, транзакционная целостность на уровне СУБД (`SELECT ... FOR UPDATE`), а не на уровне договорённостей в коде
- **Биллинг и подписки** — платёжные потоки с ручной модерацией, компенсирующие откаты при отказе внешнего API, скидки, промокоды, реферальные программы, акты сверки
- **Сайты и магазины** — Nuxt 4 с серверным рендером и админкой для владельца, WordPress с кастомной темой и собственными типами записей, миграция контента между CMS с картой редиректов, SEO-разметка (Schema.org, JSON-LD, sitemap, hreflang)

- **DevOps** — Docker Compose, healthcheck-зависимости между сервисами, автобэкапы с ротацией, изоляция сайтов на одном сервере, деплой и сопровождение на bare-metal

#### 🔫 Phygital Лазертаг — прошивки ESP32 и хаб на Raspberry Pi

**B2B-система для парков: прошивки, хаб и админка инструктора.**

Тагер и повязка на ESP32, хаб на Raspberry Pi 5. Урон считается на краю сети: повязка сама вычитает HP и сама шлёт стрелку хитмаркер, хаб только агрегирует события. Игра не останавливается, если связь с хабом пропала.

- Единый источник правды — `protocol.yaml` и `pinout.yaml`, из них генерируются константы для Python, заголовки для C++ и документация
- Python — эталон, C++ обязан совпадать бит в бит; сверка golden-векторами в CI на каждый коммит
- Прошивка на весь парк одна: номер комплекта привязывается в админке по MAC и уезжает в NVS, сгоревшая плата меняется без пересборки
- Обновление прошивок по воздуху с раздачей образов хабом
- Симулятор парка и нагрузочный прогон позволяют отладить всю игровую логику до сборки физических прототипов
- LoRa 433 МГц — аварийные команды в обход WiFi; брокер без анонимных подключений, права на топики генерируются из контракта

#### 📡 Переговорка (ToshaStream) — стрим-сервер с голосовой связью

**Голосовая, чат и эфир для своих — заодно инфраструктура для рабочих созвонов.**

Начиналась как замена голому `nginx-rtmp`, который рвал трансляцию и пускал любого, кто знал IP. Поток идёт по SRT поверх UDP с переспросом потерь, два качества одновременно — родное 3440×1440 и облегчённое для мобильного интернета. Доросла до сервиса с ролями, временными учётками и мобильным интерфейсом.

- Просмотр в браузере через HLS, с задержкой меньше секунды через WHEP, в VLC через RTSP и SRT
- Эфир и голос закрыты проверкой сессии на уровне nginx (`auth_request`), для внешних плееров — отдельный секрет
- Роли гость / свой / админ живут в базе и меняются на ходу; учётки на время — от трёх часов до бессрочных
- Голосовая на WebRTC-mesh со своим TURN: голос через сервер не идёт вовсе
- Записи эфиров с названиями, чат поверх игры отдельным окном (Document PiP), телефон вкладками, десять палитр и шрифтов
- Три текстовых чата с историей в SQLite (90 дней), «выйти везде» на случай потерянного устройства
- Видео на сервере не перекодируется — оба качества кодирует видеокарта на ПК

`Go` `MediaMTX` `SRT / HLS / WHEP` `WebRTC` `coturn` `SQLite` `nginx` `Docker`

#### 🎧 OshaPlay — аудиофильский плеер для Android с bit-perfect на USB-ЦАП

**Плеер, который говорит с ЦАПом напрямую, минуя системный микшер.**

Системный микшер Android ресемплирует любой звук до своей частоты вывода — 24-битный FLAC 96 кГц доходит до ЦАПа уже изменённым. OshaPlay уходит в обход микшера и говорит с ЦАПом по USB Audio Class: трек — в исходной частоте и разрядности, громкость — силами самого ЦАПа.

- Свой ресемплер для частот, которых нет у ЦАПа (88.2/176.4 кГц), искажения ниже −130 дБ
- Проверка настоящего lossless по спектру — ловит перекодировку из MP3 и растянутый CD под видом Hi-Res, фильтр «Подделки»

#### 🔓 UNLOCK — сервис интерактивных открыток и адвент-календарей

Получатель попадает не на открытку, а в закрытый терминал: нужен пароль. Забыл — включается Recovery Protocol с личными вопросами. Ввёл верно — терминал расцветает в тему, и дальше три экрана, где получатель сам собирает вечер. Выбор прилетает владельцу в Telegram.

#### 💰 Финансовый ассистент — учёт денег из банковских выписок

**Telegram-бот и веб-дашборд: PDF-выписки четырёх банков, свободный текст, голосовые и чеки.**

Принимает выписки ВТБ, Сбербанка, Т-Банка и Озон Банка и сообщения о тратах в свободной форме, сводит всё в одну картину и отделяет бизнес от личного.

- Банк, счёт и карта узнаются по самой выписке; перекрывающиеся периоды не задваиваются, переводы себе не считаются доходом
- Свободный текст, голосовые и фото чеков: простое — правилами, сложное — Google Gemini; ручная запись потом сливается с той же операцией из выписки
- Ночной разбор неизвестных продавцов одним запросом к модели, утром — категории и список на правку кнопками
- Направления бизнеса, реинвестиции, долги по людям, постоянные платежи, бюджеты с предупреждением на 80 % и 100 %
- Дашборд как Telegram Mini App: сравнение месяцев, покупки по позициям чеков, выгрузка CSV/XLSX
- Второй пользователь со своими счетами, ежедневный бэкап с проверкой, внешний мониторинг живости, автотесты

`Python 3.13` `aiogram 3` `FastAPI` `PostgreSQL 17` `SQLAlchemy 2.0 async` `pdfplumber` `Google Gemini` `Docker`
