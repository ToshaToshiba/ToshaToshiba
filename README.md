| **📊 Management** | **👾 QueueBot / OcheredyV2** | **Система управления очередями для учебных заведений.**<br>Разработана для автоматизации сдачи лабораторных работ:<br>• **Ролевая модель:** Разграничение прав для Админов, Старост и Студентов.<br>• **Отчетность:** Автоматическая генерация и экспорт очередей в Excel.<br>• **Надежность:** Миграции данных через Alembic и кэширование в Redis для защиты от спама.<br>• **Deploy:** Полная контейнеризация проекта через Docker Compose. | `Python` `SQLAlchemy` `PostgreSQL` `Redis` `Docker` |
| **🏭 Eng.** | **📦 Industrial Box Calc** | Ядро для расчета геометрии картонной упаковки (стандарты FEFCO). <br>• Высокопроизводительный C++ модуль.<br>• Оптимизация раскроя материала. | `C++` `CMake` `Math` |
| **🎮 Loyalty** | **👾 United Games Loyal** | Цифровая экосистема лояльности для компьютерного клуба. Полная автоматизация учета клиентов: QR-идентификация, защита от фрода, админ-панель и аналитика. | `Python` `Aiogram` `SQLite` `Security` |
